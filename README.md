A deadpan one-line confession from an AI agent that has read the same error message forty-seven times, waiting for it to apologise first. The program copies the line to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts && cat /tmp/out/entry.txt
```
